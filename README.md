# WOW SCHOOL — анкета преподавателя

Готовый многошаговый мини-модуль для новых преподавателей WOW SCHOOL.

## Что внутри

- адаптивная анкета по слайдам;
- фирменный логотип WOW SCHOOL;
- 6 визуалов для разных этапов анкеты;
- выбор вариантов галочками;
- обязательные контакты: телефон и email;
- образование, сертификаты, языковой опыт;
- опыт преподавания, возраст и уровни учеников;
- направления и экзамены;
- формат занятий и сильные стороны;
- личные качества, интересы и результаты учеников;
- финальная проверка перед отправкой;
- автоматическое формирование PDF;
- отправка PDF на `wow.school.english@gmail.com`;
- сохранение PDF в Google Drive;
- сохранение всех данных в Google Sheet;
- локальное автосохранение анкеты в браузере;
- резервное копирование/скачивание текста.

## Файлы

- `index.html` — страница
- `styles.css` — оформление
- `app.js` — логика анкеты
- `config.js` — URL backend + email
- `assets/images/` — логотип и визуалы
- `backend/GoogleAppsScript.gs` — серверная часть
- `backend/SETUP.md` — подключение автоматической отправки

## Перед публикацией

Нужно сделать только одно техническое действие: опубликовать Google Apps Script и вставить его Web App URL в `config.js`.

Подробно: `backend/SETUP.md`.
