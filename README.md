# WOW SCHOOL — анкета преподавателя (Web3Forms)

Эта версия не использует Google Apps Script.

## Как работает

Преподаватель проходит анкету на GitHub Pages и нажимает «Отправить анкету».
Все ответы приходят письмом на `wow.school.english@gmail.com`.

## Подключение — один раз

1. Откройте https://web3forms.com/
2. Введите `wow.school.english@gmail.com` и получите Access Key на почту.
3. Откройте `config.js`.
4. Вставьте ключ сюда:

   window.WOW_WEB3FORMS_ACCESS_KEY = "ВАШ_КЛЮЧ";

5. Загрузите обновлённые файлы на GitHub Pages.

Готово. Сервер, Google Apps Script и Google Cloud не нужны.

## Если ключ ещё не добавлен

Форма не ломается: преподавателю откроется готовое письмо на адрес WOW SCHOOL и автоматически сохранится текстовая копия анкеты.

## Важно

Бесплатная схема отправляет структурированную анкету прямо в теле письма. Если позже понадобится именно PDF-вложение, можно отдельно подключить платную загрузку файлов или другой сервис.
